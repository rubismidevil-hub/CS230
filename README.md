Briefly summarize The Gaming Room client and their software requirements. Who was the client? What type of software did they want you to design?
  The Gaming Room is a game developer company that hired CTS to assist with developing a multi-platform game for distribution. The Gaming Room was looking to release an expanded version of their game Draw it or Lose it in order to reach a broader gaming audience. The goal was planned for a full release across PC (Mac, Linux, and Windows), Console (Xbox, PS, etc.) and mobile devices. The request was to create the game in in a manner that it would be able to function smoothly across all platforms and have the game include individuals from any and each platform at the same time in any given round without risk of increased latency or crashing due to issues that can occur with lower RAM or accessible storage for each device.

How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?
  I looked at the overall need of the user rather than just smaller pieces. For example, the user need the abiltiy to launch the app across multiple devices, so rather than looking at what it would take to launch on each individually, it was easier to look for what had the most options when coding to create a base that would launch across the most OS's as possible and start there. As for why it is important to llok at the user's needs, that is somewhat the point of creating applications and coding. By creating a singular need platform, the end result can become either insignificant or have such a small distribution that it will never reach the target numbers. By assessing what the user needs are and adapting from there, you can broading the outreach of the end applciation and increase the distribution and user base.
